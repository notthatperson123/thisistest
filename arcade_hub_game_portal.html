GitHub Pages Deployment Guide

Step-by-step instructions for hosting this portal and your custom web games.

📁 my-game-arcade-repository/

├── 📄 index.html (This portal file!)

└── 📁 games/

├── 📁 space-shooter/

└── 📄 index.html

└── 📁 retro-platformer/

└── 📄 index.html

1

Upload `index.html` to GitHub

Create a GitHub repository, upload this `index.html` file into the root folder, and commit changes.

2

Add Your Custom Game Folders

Create a folder named /games/ in your repo. Add subfolders for each game containing an index.html file.

3

Enable GitHub Pages

Go to Repo Settings -> Pages. Set Source to Deploy from a branch, select main branch /(root), and click Save.

4

Link Games in Arcade Nexus

Click "+ Add Game" on this website and type relative paths such as ./games/space-shooter/index.html.
